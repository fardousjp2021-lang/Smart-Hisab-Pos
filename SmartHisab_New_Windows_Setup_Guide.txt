প্রিয় ইউজার,
আপনার প্রজেক্টের সমস্ত কোড এবং সেটিংস গিটহাবে (GitHub) ১০০% নিরাপদে সেভ আছে।
ভবিষ্যতে আপনি কম্পিউটার পরিবর্তন করলে বা নতুন উইন্ডোজ (Windows Setup) দিলেও 
কোনো চিন্তার কারণ নেই। নিচের সহজ নিয়মগুলো অনুসরণ করলেই সফটওয়্যার আবার আগের মতো চালু হয়ে যাবে।

--------------------------------------------------------------------------------
১. উইন্ডোজ দেওয়ার সময় সতর্কতা:
--------------------------------------------------------------------------------
- সাধারণত উইন্ডোজ দেওয়ার সময় শুধু C: Drive ফরম্যাট হয়।
- আপনার প্রজেক্টের ফোল্ডারটি D: Drive-এ রয়েছে (D:\SOFT\AI\course\SMART HISAB\SMART HISAB)।
  তাই উইন্ডোজ দেওয়ার সময় D: ড্রাইভ ফরম্যাট না করলে প্রজেক্টের কোনো ফাইল মুছবে না।
- আপনার যদি কোনো গোপন API Key বা .env ফাইল থাকে, সেটি একটি পেনড্রাইভ বা গুগল ড্রাইভে 
  কপি করে রাখুন।


--------------------------------------------------------------------------------
২. নতুন উইন্ডোজে যে ৩টি সফটওয়্যার ডাউনলোড করতে হবে:
--------------------------------------------------------------------------------
নতুন উইন্ডোজ ইনস্টল করার পর আপনার ব্রাউজার দিয়ে নিচের ৩টি সফটওয়্যার ডাউনলোড করে ইনস্টল করুন:

১) Node.js (LTS Version):
   - ডাউনলোড লিংক: https://nodejs.org/
   - কেন লাগবে: প্রজেক্টের সার্ভার রান করা ও প্যাকেজ পরিচালনার জন্য।
   - ইনস্টল নিয়ম: ডাউনলোড হওয়া ফাইলটি ওপেন করে শুধু "Next" চেপে ইনস্টল শেষ করুন।

২) Git for Windows:
   - ডাউনলোড লিংক: https://git-scm.com/download/win
   - কেন লাগবে: গিটহাব থেকে কোড নামানো ও কোড আপডেট পাঠানোর জন্য।
   - ইনস্টল নিয়ম: ডাউনলোড হওয়া ইনস্টলারটি ওপেন করে ডিফল্ট সেটিংসে "Next" চেপে ইনস্টল করুন।

৩) Google Antigravity (অথবা VS Code):
   - কেন লাগবে: কোড দেখা, এডিট করা ও AI এর সাথে কাজ করার জন্য।


--------------------------------------------------------------------------------
৩. প্রজেক্ট পুনরায় চালু করার ধাপসমূহ:
--------------------------------------------------------------------------------

[ধাপ ১] গিট কনফিগারেশন সেট করুন:
নতুন উইন্ডোজে কমান্ড প্রম্পট (Command Prompt / CMD) ওপেন করে নিচের দুটি লাইন 
কপি করে এন্টার দিন:

git config --global user.name "fardousjp2021-lang"
git config --global user.email "fardousjp2021@gmail.com"


[ধাপ ২: কেস ক] যদি আপনার D: ড্রাইভ অক্ষত থাকে (ফোল্ডার ডিলিট না হয়):
কমান্ড প্রম্পটে গিয়ে শুধু নিচের কমান্ডগুলো লিখুন:

cd /d "D:\SOFT\AI\course\SMART HISAB\SMART HISAB"
npm run dev

ব্যাস! আপনার লোকাল সার্ভার http://localhost:3000/ এ রানিং হয়ে যাবে।


[ধাপ ২: কেস খ] যদি হার্ডডিস্ক সম্পূর্ণ নতুন বা ফরম্যাট হয়ে যায় (GitHub থেকে আনা):
কমান্ড প্রম্পট ওপেন করে নিচের কমান্ডগুলো দিন:

cd /d D:\
git clone https://github.com/fardousjp2021-lang/Smart-Hisab-Pos.git
cd Smart-Hisab-Pos
npm install
npm run dev

কয়েক সেকেন্ডের মধ্যে গিটহাব থেকে সমস্ত ফাইল ডাউনলোড হয়ে ইন্সটল হয়ে যাবে এবং চালু হবে।
